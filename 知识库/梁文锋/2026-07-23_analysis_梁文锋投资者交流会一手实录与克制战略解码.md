## 2. 决策操作系统：四个咬合的机制

### 机制一｜克制经济学：拿得少的打败拿得多的

这是全场唯一被他反复推导、而非断言的东西，是整套系统的地基：

```
AI 终局占人类 GDP 约 10%（他的假设）
  → 有人想拿其中 5%  → 被只想拿 1% 的人打败
  → 只想拿 1% 的人   → 被只想拿 0.1% 的人打败
  → 下界：拿得太少活不下去 → 存在均衡点
  ∴ 「愿景拿得多」本身就是竞争劣势，不需要真的拿到钱就已经输了
```

关键推论：他把**定价**从"利润最大化"改成**"十个月回本"这一常数**，于是开源不再与商业化冲突——因为六倍利润下第三方部署无利可图，而百倍利润才会被第三方套利。**开源的可持续性是定价策略的函数，不是价值观的函数。** 这是本场最反直觉也最硬的一段推理。

**反例边界**：该机制成立的前提是"总盘子足够大 + 需求无价格弹性 + 自己成本领先数倍"。若行业收敛到小市场（如传统软件），或竞争对手补上成本差距，"拿得少"就退化为纯粹的自我削弱。他自己也承认下界存在。

### 机制二｜唯一核心利益：团队稳定性 = 做成 AGI 的概率

> "只要我能够保持团队的稳定性，我一定能做成 AGI，就这么简单。"

他把所有战略动作都还原为这一个变量的函数：
- 不树敌（不与任何大厂小厂为敌，甚至愿意帮阿里/智谱/月之暗面）→ 环境更好 → 团队稳
- 开源与降价 → 员工成就感与凝聚力 → 团队稳
- 不加班、正事不超一半工时 → 研究需要松弛 → 团队稳
- 本轮融资 → 期权兑现 → "风险得到比较大的解除"

**其余一切（钱、卡、资源、进度）都被他定义为"只影响早半年晚半年"的非核心变量。** 这是一个极端简化的目标函数，也是他敢于在 C 端/B 端上"随手捡芝麻"的底气。

### 机制三｜阶梯路线图：每一步都不白走

```
语言模型 → CoT（去年）→ Agent（今年）→ 持续学习（下一个瓶颈）
        → 渐进奇点（AI 加速 AI 研究，非线性但无临界点）→ 具身智能（终点）
```

两个非共识判断：
1. **世界模型、视频生成、3D 不在主线上**——"跟智能的上限没有太大关系"；视频生成"在商业上是个好生意，但跟智能没关系，我们不会因为它是好商业而做它"。多模态与搜索一样，是**组件不是主线**。
2. **路线图顺序的选择标准是"省力"而非"正确"**——先持续学习再具身，是因为后面的技术可以用前面的技术来开发；反过来先做具身"是一个很苦的活"。**他在用"能不能不加班"来选技术路线**，这是极罕见的决策锚点。

配套的自用优先原则：**"我们做的模型，第一目标不是大家用得好用，而是我们自己用得好用"**——因为模型提升 DeepSeek 自身研发效率，是通往 AGI 最快的路径。

### 机制四｜降维打击：产品是 AGI 的副产物

C 端与 B 端都不是目标，是"通往 AGI 必经台阶的产出物顺手商业化"。他给出的证据链：去年春节爆火"不在剧本里"，一度不想维护那些用户"但用户赶都赶不走"；今年 B 端增长"跟同行比应该也是比较好的"，而"我们根本没有花很大精力"。

他给出的机制解释不是玄学，而是**组织优势**：AGI 愿景能凝聚更优秀的人 → 组织与人才优势 → 在低一级的技术层面形成降维打击。"最想得到的东西反而得不到，没那么在意的反而容易得到。"

## 3. 认知偏好与盲区

- **决策锚点排序**：客观规律/历史观（"独占一定被历史抛弃"）> 算账（十个月回本、GDP 百分比推演）> 直觉（"至少符合我的直觉"）。**几乎不用叙事和情绪。**
- **风险偏好**：在资源上极度激进（"半年之内把钱全变成卡是最理想的""愿意付一定溢价"），在业务边界上极度保守（能不做就不做）。**这是一个把所有 risk budget 压在单一变量上的结构。**
- **表达特征**：大量"我觉得/可能/应该"软化词；唯一一次绝对化出现在团队稳定性上；反复自我修正与承认不确定（"我还没有想得很明白"）；决策机制自述为**共识驱动**而非集权（"我在公司内的权威建立在共识的基础上"）。
- **系统性盲区（三项）**：
  1. **把"人才无差距"论证得过于轻巧**——"就是同一批人"、"人才短缺都是阶段性的"，用飞行员类比消解了顶尖研究者的稀缺性，与他自己"一半核心研究员在标数据"的资源紧张状态存在张力。
  2. **对地缘政治变量近乎不设防**——全场把中美差距归结为纯资源问题，几乎不讨论制裁升级、算力禁运深化、开源合规风险等非市场变量。
  3. **"团队稳定 = 一定做成"是未经检验的等式**——技术路线可能整体走错（持续学习若三五年不破），此时团队再稳也无用。他把技术风险默认为"只影响早晚"。

- **对撞黄哥模型 v3.2 的「算力资本化/产业银行」章节**：黄哥的英伟达论证建立在 CUDA 生态护城河与算力金融化之上；梁文锋从**使用方视角**给出了相反的边际信号——CUDA 护城河正被 AI 写码能力 + 高级语言（TileLang）+ 计算卡游戏卡解耦三重瓦解，且切换成本只有 1–2% 效率损失。**这是知识库里第一份来自一线使用方、直指黄哥核心假设的反证，值得在下次模型刷新时正式对撞。**
- **呼应黄哥「训练/推理二分」（#160）**：梁的路线图把资源全押在训练与持续学习上，明确不做世界模型/视频生成，可作为"训练侧仍是主战场"的一手佐证。

## 6. 反方视角

**这份稿子最可能错在"它是一次融资路演"这件事上。** 时间点是 2026-05-20 的投资者交流会，语境是刚完成融资、面对已上船的股东——"克制""善意""愿景驱动"在这个场合具有极高的叙事收益，而"我们只赚六倍利润""我们不加班""我们没有组织"这类反商业常识的表述，恰恰是最能提升估值溢价的稀缺人设。**一手稿的"一手"只保证了话被准确记录，不保证话被真诚说出。** 检验方法只有一个：看后续 12–24 个月的实际动作是否与这些承诺一致——尤其是"最强模型是否真的开源"和"是否真的不做垂直 Agent / 不做超级 App"这两条，它们成本最高、最难用言辞对冲，因此判别力最强（已入表 #74/#76）。

第二个风险更技术性：**他对国产芯片的乐观带有强烈的利益相关性**——DeepSeek 买不到足够英伟达卡，"看好国产替代"既是判断也是必需品。"未来一年国产生态没有问题"是本稿中**最激进、也最容易被证伪**的一条，应作为检验他判断质量的首要标尺。
