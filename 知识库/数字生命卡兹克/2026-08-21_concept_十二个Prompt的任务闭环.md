# 十二个 Prompt 的任务闭环

来源：2026-08-21T121722+0800都Agent时代了，我还是想分享给你这12个我最常用的Prompt。.md
分析时间：2026-08-21 | 核心判断：这 12 个 Prompt 的价值不在措辞，而在把 AI 协作拆成“澄清问题—建立理解—生成解法—做出决策—用行动认识自己”的五阶段闭环；最值得迁移的是信息不足时只问一个关键问题、观点必须给失效条件、重大决策优先设计可逆实验。

## 一、原文不是“提示词合集”，而是一套任务路由器

12 个 Prompt 被放进五个场景：

| 阶段 | 工具 | 真正解决的问题 |
|---|---|---|
| 问清问题 | 苏格拉底式提问 | 用户说出口的问题是否是真问题？ |
| 学习 | 双层解释、反向拆解、横纵分析、事实核查 | 从听懂、模仿、研究到验真的不同深度如何选择？ |
| 解决问题 | 专家会诊、第一性原理、跨领域借解 | 是需要多视角、推倒假设，还是迁移别处机制？ |
| 决策 | 双向钢人、最小实验 | 继续辩论还是进入现实验证？ |
| 认识自己 | 隐藏天赋、人生设计 | 如何把过去证据与未来原型连接起来？ |

它隐含了一条很实用的流水线：

`模糊困惑 → 可回答问题 → 事实与机制 → 多条候选路径 → 关键分歧 → 最小实验 → 新证据 → 更新自我模型`

因此“都 Agent 时代了还谈 Prompt”并不矛盾。Agent 解决的是执行半径，Prompt 解决的是目标、边界、证据与停止条件；执行能力越强，问题定义错误的代价反而越大。

## 二、相对 2026-05-20 内容方法论的增量

上一篇历史样本强调内容生产的“信息 30% / 角度 60% / 创作 10%”、陌生化与节奏控制；本篇从“怎么生产好内容”扩展为“怎么组织人与 AI 的协作”。新增的稳定偏好有四条：

1. **先定义任务类型，再调用能力。** 不用一个万能 Prompt 解决所有问题，而是按澄清、学习、求解、决策、自我探索路由。
2. **把追问预算写进交互协议。** 多个模板要求每次只问一个问题、最多若干主问题、信息足够立即停止，防止“无限拷打”。
3. **让不同视角显式争论。** 专家会诊不是角色扮演，而是要求各视角给改变判断的新证据，并互相质疑假设。
4. **把思想输出接到现实反馈。** 双向钢人之后不是永远论证，而是设计低成本、可逆、有指标和停止线的最小实验。

这说明作者的 Prompt 观已经从“让模型写得更好”迁移到“把认知过程做成可检查的工作流”。

## 三、最有迁移价值的四个设计原则

### 1. 一次只问一个最可能改变结论的问题

这条规则同时出现在苏格拉底问诊、专家会诊、双向钢人和生涯对话中。它的价值是让下一问依赖上一答，避免静态问卷；同时用“是否改变结论”淘汰礼貌性追问。

失效边界：当用户需要快速异步收集大量事实，逐轮追问会显著拖慢效率，此时应先给最小信息清单，再对关键冲突单问。

### 2. 把事实、解释、价值判断和目标分开

事实核查模板要求先拆事实与结论，苏格拉底模板又加入价值判断和目标。四分法可直接迁移到研究、投资、产品复盘和争论：很多“事实冲突”其实是目标不同，很多“价值冲突”又伪装成数据争议。

失效边界：分类不是终点。即使事实都对，也可能因样本选择、基准和因果桥接错误得出坏结论。

### 3. 让反方说明“什么证据会让我改变判断”

专家会诊与双向钢人最强的部分不是列正反观点，而是要求双方给适用条件、最大风险和改变结论的变量。它把辩论从立场表演转成可更新的模型。

失效边界：模型可能虚构“专家共识”或平均化真正冲突。原文明确禁止模仿真实人物，但还应补一条：涉及事实时必须引用外部证据，角色视角不能替代资料。

### 4. 用可逆实验结束空想

最小实验模板要求先找 3 个假设，再选最可能改变结论的一个，规定周期、资源、指标、继续线和停止线。这是全篇最具行动价值的结构：不是追求一次做对，而是购买信息。

失效边界：有些决策不可逆或反馈延迟很长，不能假装都可“小试”。此时应使用情景演练、预演失败和安全冗余，而不是硬造实验。

## 四、三个需要警惕的地方

### 1. Prompt 很完整，不等于证据会自动出现

横纵分析法要求一手来源、时间线、竞品、未来路径，规格很好；但模型若不能联网、资料不足或引用不可靠，长报告只会把不确定性写得更像确定性。输出长度 1—3 万字也可能诱导“为了完整而填空”。

### 2. 多角色可能制造伪分歧

让同一个模型扮演三位专家，底层仍共享同一知识与偏差。适合用于发现角度，不适合把角色数量当独立证据数量。真正高风险的议题仍需不同来源、不同数据和真实专业审阅。

### 3. 心理学框架容易过度解释个人经历

“隐藏天赋”组合盖洛普、心流与荣格，容易把零散经历拼成一个过于漂亮的身份故事。原文要求证据不足时用“可能”并继续追问，这是保护条款；还应增加反例搜寻和 30 天行为验证，避免标签反过来限制人。

## 五、比 12 个独立模板更高效的组合方式

### 研究任务

`苏格拉底澄清 → 横纵分析 → 事实核查 → 反向拆解 → 最小实验`

先明确研究决策，再建全景；对承重事实单独核查；最后把优秀案例拆成可执行练习。不是每次都跑满链条，简单概念只用“双层解释”即可。

### 复杂方案

`第一性原理 → 跨领域借解 → 专家会诊 → 双向钢人 → 最小实验`

先拆掉默认假设，再扩展机制候选；用互补视角找冲突，最后把争论压缩成一个可验证变量。

### 人生选择

`苏格拉底澄清 → 能量/经历证据 → 三个五年版本 → 双向钢人 → 原型体验`

自我认识不应止于报告。真正的输出是下一次对谈、一天到一周的体验和随后更新的判断。

## 六、可复用的“最小 Prompt 骨架”

不必背 12 段长模板，大多数任务可压缩为六格：

1. **目标**：我要解决什么，不解决什么？
2. **事实**：已知材料、来源和截止时间是什么？
3. **约束**：时间、资源、风险与不可接受结果是什么？
4. **分歧**：最强反方与关键未知变量是什么？
5. **输出**：我要判断、方案、清单还是实验？
6. **停止条件**：信息不足问哪个问题；什么结果支持继续或停止？

骨架比华丽角色设定更耐模型升级，因为它约束的是任务结构而非语气。

## 七、是否值得建立专属模式

**暂不建议。** 目前只有两篇样本：一篇内容创作方法论，一篇 Prompt 工作流，已能看出作者擅长把经验产品化、强调交互节奏与可执行模板，但不足以判断这是稳定认知体系还是选题共同点。建议继续沿用学习模式；累计到 4—5 篇且持续出现“任务路由—单问迭代—反方证据—最小实验”四件套时，再考虑建立“AI 协作方法论增量模式”。

## 八、反方视角

这套体系最可能错在把复杂问题过度流程化：结构能防漏项，却不能替代领域知识、真实数据和承担后果的人。Prompt 的上限不是模型愿意写多少，而是输入证据有多好、用户是否愿意在现实里验证。换句话说，提示词能帮人更清醒地走路，但不能替人长出路面。
