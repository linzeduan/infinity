# 海外玻璃基板三级标的优先级框架

来源：260617海外玻璃基板最值得关注的战略性标的.jpg  
分析时间：2026-06-17 | 核心判断/核心洞察：玻璃基板投资不是买"做玻璃的公司"，而是买让玻璃完成半导体化的五道工序上的铲子——良率检测(P0)>平台型(P1)>中后段工艺(P2)；战资一句：Onto + LPKF + SKC/Absolics + Samsung EM

---

## 新增原则

**原则A：玻璃基板半导体化五步工序 → 对应投资层级**

真正有战略价值的公司，卡在玻璃变成芯片封装基板的五道工序上：

| 工序 | 功能 | 投资层级 |
|------|------|---------|
| 1. TGV打孔 | 把玻璃变成可互连的通孔平台 | P0（LPKF） |
| 2. 检测测量 | 决定良率能否被接受 | P0（Onto Innovation） |
| 3. 玻璃基板平台 | 决定最终基板商业化程度 | P1（SKC/Absolics） |
| 4. 电镀填铜/RDL | 让玻璃正式开始电气连接 | P2（MKS/Atotech） |
| 5. 后道先进封装 | 完成芯片系统整合 | P2（SUSS MicroTec） |

**原则B：三级优先级框架（P0/P1/P2）**

**A级 P0 — 最值得先研究（率先建仓逻辑）**
- **Onto Innovation**（检测量测龙头）：站在"良率"这个最关键位置；覆盖玻璃基板检测+量测+面板级封装；不押单一技术路线，确定性最高。关键词：**良率卖铲人**。
- **LPKF**（TGV打孔核心）：最纯的 TGV 打孔弹性标的；LIDE 路线代表性方案；高弹性但二元性强（订单集中+产品节奏风险）。关键词：**高弹性，但二元性强**。

**B级 P1 — 平台型核心玩家（配置逻辑）**
- **SKC / Absolics**（玻璃基板本体平台）：最接近纯度最高的玻璃基板标的；核心观察：客户认证进度+商业化速率。关键词：**本平台，量产验证**。
- **Samsung Electro-Mechanics**（封装基板平台）：传统封装基板巨头向玻璃迁移；背靠三星生态，产业化路径更稳；弹性低于P0但确定性更强。关键词：**平台型，偏稳健**。

**C级 P2 — 中后段工艺卖铲人（期权逻辑）**
- **MKS / Atotech**（电镀填铜/RDL）：填铜和电镀是关键中段工序，受限于整体产线节奏。
- **SUSS MicroTec**（后道设备）：受益于先进封装后段工艺升级，玻璃基板是重要加分而非唯一主线。

**战略风向标（非弹性标的）**：TSMC / Intel / Samsung — 定义路线与量产节奏，是产业风向标但不是最纯玻璃基板弹性体系。

## 强化或修正的已有原则

**强化 CoWoS→CoPoS 分析（黄哥 06-05 篇）→ 首次落地到海外可操作标的**  
06-05 篇建立了"硅中介层瓶颈→玻璃基板机会→面板厂转型"的宏观框架，本篇是首次将该框架落地到具体可交易标的，且附上三级优先级和投资逻辑，可直接作为选股行动指南。

**强化"铲子投资五层框架"：良率环节（Onto）= 最高确定性**  
在 SoC 铲子框架中，EDA/IP 之所以在第一层，是因为它是所有其他层的前提条件（设计不出来，制造无从谈起）。良率检测（Onto Innovation）在玻璃基板产业链中具有同等地位——良率不通过，所有下游工序都是废品，所以良率工具商是最强铲子。

**新视角：Onto Innovation 作为跨赛道的共同受益者**  
黄哥此前分析了 CoWoS/先进封装产业链，Onto Innovation 同样是先进封装良率检测的核心玩家。这意味着 Onto 同时卡在了 CoWoS 和玻璃基板两条产业升级路径上——无论哪条路线主导，Onto 都是受益者，这是"路线无关"的稀缺属性。

## 与模型矛盾点

**无显著矛盾。本篇是 06-05 框架的自然延伸，补充了可操作维度。**  
唯一需要追踪的潜在矛盾：黄哥 06-05 对面板厂（京东方/TCL华星）转型寄予厚望，而本篇并未将其列入优先级框架（仅在战略风向标中提及 Samsung，未提中国面板厂）。可能因为海外标的更纯，或者认为A股面板厂的转型不确定性更高。

**反方视角**：玻璃基板的技术路线尚未被任何一家大客户正式量产认证，目前仍在良率攻关阶段——这意味着 P0/P1 级标的的"铲子"实际上是在给一个还未完全确定会成功的基础设施做工具供应，若英特尔最终在玻璃基板上量产失败或延期5年，整个框架的前提条件就不成立了，这个风险在黄哥图表中未被量化。
