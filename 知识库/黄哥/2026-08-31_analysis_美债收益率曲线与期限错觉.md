# 美债收益率曲线的定价骨架与期限错觉

## 一、有效增量：从“一张车票”推进到“一条价格曲线”

上一篇《钱是什么》把钱描述成运输购买力的车票，本篇继续回答：这张车票在两年、十年和三十年分别卖多少钱。去掉类比后，原文的有效骨架是：

```text
美元是计价单位
  → 美国政府按不同期限发行可交易债权
  → 市场每天给这些债权重新报价
  → 不同期限的到期收益率连成收益率曲线
  → 这条曲线成为许多美元资产定价时的基准底座
```

“美债是美元资产的定价底座”方向成立，但原因不只是“美国信用最高”。美国财政部将美债市场称为全球最深、最具流动性的市场，并明确说它提供基准无风险收益率曲线、充当高质量抵押品和流动性资产。这里的“无风险”是市场定价惯例，主要指低信用风险基准，不等于没有通胀、期限、流动性或提前出售的价格风险。

因此，更精确的说法不是“美债给所有资产定价”，而是：**美债曲线提供美元名义现金流的基础折现锚；其他资产还要叠加信用、流动性、股权、汇率和情景风险溢价。** 它是地基，不是整栋楼的报价单。

## 二、必须拆开的四组概念

### 1. “美债”不是一种单一证券

美国政府发行的可交易国债包括 Bills、Notes、Bonds、TIPS 和浮息票据。TreasuryDirect 的期限划分是：Bills 在一年以内，Notes 为 2、3、5、7、10 年，Bonds 为 20 或 30 年；Notes 与 Bonds 通常每半年付息。原文只列“几个月、2年、5年、10年、30年”，适合作为入门示意，但不是完整分类。

### 2. 票面利率、成交价格与到期收益率不是同一个数

原文例子里，面值 100 美元、每年付 5 美元，对应 5% **票面利率**。票息在发行后固定，但债券可以在二级市场交易；价格变化后，投资者按买入价与剩余现金流计算的才是**到期收益率（YTM）**。TreasuryDirect 给出的关系是：YTM 高于票面利率时价格低于面值，YTM 低于票面利率时价格高于面值。

这能保留原文最重要的一句：

```text
债券价格下降 ↔ 到期收益率上升
债券价格上升 ↔ 到期收益率下降
```

但“收益率是根据最新票息交易旧债得到的受益”不够准确。收益率不是某一笔票息，而是让买入价格等于全部剩余现金流现值的折现率。

### 3. 美联储直接定的是隔夜政策利率，不是整条美债曲线

原文把收益率曲线比作狗，并说美联储牵着绳、2年期是脑袋、10年期是身体、30年期是尾巴。这个比喻能表达“越近越受政策影响，越远越受长期变量影响”，但“美联储定义短中长期价格”说得过满。

美联储直接设定的是联邦基金利率目标区间，即银行隔夜准备金借贷的政策锚。2年期美债对未来政策路径很敏感，却仍由市场交易形成；10年和30年也不是脱离美联储的自由尾巴。更稳的期限结构骨架是：

```text
n年期国债收益率
≈ 未来n年预期短期利率的平均值
+ 期限溢价
```

若继续拆，预期短期利率又受增长、通胀与政策反应函数影响；期限溢价则会受通胀不确定性、财政供给、投资者风险偏好、资产负债表需求和市场流动性影响。纽约联储的研究显示，中长期收益率的变化不能只由预期短端利率解释，期限溢价经常是重要来源。

### 4. 期限更长不等于收益率必然更高

原文沿用上一篇“时间越长、风险越大、补偿越高”的直觉。它适合解释久期风险，却不能当作收益率曲线的硬规则。若市场预期未来降息、增长下行或长期资产需求很强，长端收益率可以低于短端，形成倒挂；期限溢价本身也会随市场状态变化。因此，2年、10年、30年不是三种彼此独立的价格，而是同一组宏观预期在不同期限上的投影。

## 三、算术核验：90美元“附近”可以，160美元不可以

原文设定一只十年期债券：面值 100 美元，每年付 5 美元。逐页核对后有两处需要分开：

1. 页面写“十年下来，本金100美元+50美元利息，合计15元”，按上下文应为 **150美元**，属于明显漏写一个“0”。
2. 当新债到期收益率升至 6% 时，旧债的固定现金流并不会变成 160 美元。若简化为每年付息一次、剩余期限仍为十年，旧债价格应为：

```text
P = 5 × Σ[1 / (1 + 6%)^t] + 100 / (1 + 6%)^10
  ≈ 92.64 美元
```

所以“价格降到90美元附近”可视作粗略直觉，但正确理由是把旧债原有的 5 美元票息和 100 美元本金按 6% 折现；不是“到期后仍然拿到160美元”。旧债持有至到期的名义现金流合计仍是 150 美元，新发 6% 票息债的名义现金流合计才是 160 美元。两者收益率相近，靠的是旧债买入价格下降，不是旧债现金流增加。

## 四、与既有模型的接口：把“美债价格表”接入四层宏观框架

本文没有改变 M9 的宏观立场，但补上了一个实用接口：**同一个“美债收益率上升”，可能由不同发动机驱动，资产含义也不同。** 可把 M9 的宏观价格四层改写为美债版：

```text
驱动力：政策路径 / 增长 / 通胀 / 财政供给 / 风险偏好
  → 传导通道：一级拍卖 / 二级交易 / 杠杆与抵押品需求
  → 政策闸门：政策利率 / 资产负债表 / 流动性工具 / 债务发行结构
  → 最终价格：2Y / 10Y / 30Y 的价格、收益率与曲线斜率
```

这也与达里欧的“债务供需缺口”形成接口：新增供给会影响期限溢价和市场清算价格，但它不是长端收益率的唯一发动机。分析时至少要问：这次变化来自预期政策路径、预期通胀，还是期限溢价？如果不拆，看到10年期收益率上升就直接解释成“美联储更鹰”或“日本抛售”，仍会落回单因果叙事。

可执行观察顺序是：先看各期限自身变化，再看 2Y–10Y 与 10Y–30Y 的曲线变化，最后用政策预期、通胀补偿、财政供给与期限溢价解释；不能先选故事再找一段曲线作证。

## 五、认知与表达画像增量

连续两篇科普确认了黄哥的稳定优势：用“车票”“狗绳—狗身—狗尾”把抽象金融概念压缩成儿童可理解的图像。新增盲区也随之确认：**比喻一旦进入正式定义，方向正确会被读成控制关系，教学近似会被读成定价公式。**

因此，使用规则应升级为两步：先用比喻记住方向，再强制翻译成“现金流—价格—折现率—风险溢价”四个对象。比喻负责开门，公式负责验票；让狗直接管理收益率曲线，多少有点超出它的岗位说明书。

## 六、反方视角与失效边界

1. **“美债是基准”不等于“美债决定一切”。** 企业现金流、信用利差、风险偏好和制度约束可以抵消或放大基础利率变化。
2. **美联储影响长端，不等于精确控制长端。** 前瞻指引和资产购买能改变预期与期限溢价，但财政供给、通胀风险和全球资金需求同样重要。
3. **收益率曲线不是单向预测器。** 倒挂常被当作衰退信号，但预测窗口、期限组合和政策环境都会影响解释，不能从一次斜率变化直接生成仓位动作。
4. **持有至到期与中途交易是两套风险暴露。** 按期收到本息不消除通胀机会成本；提前出售则新增价格与流动性风险。
5. **本文不提供当前利率或买卖建议。** 原文使用的 4%、5%、6% 都是教学例子，不应误当作 2026-09-01 的市场报价。

## 七、模型与预测处理结论

本篇属于 M9 后第 7 篇，提供“期限收益率＝预期短端路径＋期限溢价”的候选接口，但没有发生防御→中性/进攻的宏观立场切换，不刷新 v5.0 主模型。原文没有给出带明确对象、期限、验证条件和失效标准的未来判断，因此不新增《预测追踪表》记录。
