## 一、核心机制：把一家公司先拆成两家

英特尔的组织事实（原文架构图）：

```
Intel ─┬─ Intel Products  ≈ AMD   → CPU / Edge / ASIC
       └─ Intel Foundry   ≈ TSMC  → 制程 / 封装 / Fab
```

这一步是**估值的前置动作，不是估值本身**。模型 v4.0 三章 C 的 SOTP 解决"怎么加"，本篇补上的是"**拆成几块、每块对标谁**"——先给每个分部找一家纯业务可比公司，再各自套倍数。可迁移到任何 IDM/多业务复合体。

## 二、增量：新增原则

### ⭐ A. 开放阵营 vs 全家桶阵营——反霸权需求本身就是一门生意

- **NVIDIA 模式**：CPU＋GPU＋NVLink＋Network＋CUDA 全家桶 → 拿走行业 **70% 利润**
- **开放模式**：Intel/AMD CPU ＋ AMD GPU / Google TPU / 自研 ASIC ＋ Broadcom 网络 ＋ 开放 Ethernet ＋ 各种软件

Intel 的第一个战略价值由此定义：**成为非 NVIDIA AI 体系里的通用 CPU 和基础设施供应商**。投资逻辑的来源不是产品更好，而是"Google、Amazon、Microsoft、Meta 不希望整个 AI 基础设施被 NVIDIA 完全控制"。**可迁移**：任何寡头行业里，第二供应商的价值可以不来自性价比，而来自买方对单一供应商的结构性恐惧——这是一条独立于产品力的估值来源。
**反例边界**：当霸主的性能差距大到让"不被控制"的成本高于收益时（Intel GPU 侧 ★1 即是），反霸权需求不会转化为订单。

### ⭐ B. ASIC 对 GPU 是替代，对 CPU 是互补——Intel 与 AMD 的性质不同

- **AMD 与 NVIDIA 是零和份额竞争**："你买 MI450，就少买 Rubin"
- **Intel 不是**：巨头自研 ASIC 越多，越需要 Host CPU / IPU / DPU / Networking / Packaging / Foundry

他给的市场结构假设（**原文自陈为"假设"**）：NVIDIA 60% / ASIC 30% / AMD 10%。在这个结构里"AMD 哭晕在厕所"，而 Intel 可以卖设计、卖 CPU、参与 ASIC 设计、再代工、最后承接封装——**吃 AI 计算总量增长的贝塔**。原文并给出已发生的锚点：Intel 已在 ASIC 型 IPU 上与 Google 持续合作。

这条**强化并给出了机制**：#C（0622 陈立武访谈）记录的"CPU:GPU 从 1:8→1:4、CPU 复权"，此前只是一个观察到的比值，本篇给出了它的因——ASIC 化本身就在制造 CPU 需求。

### C. 三条控制点排序（他给的机会顺序）

1. **代工制造与先进封装**——"这个世界不缺 CPU 设计公司，也不缺 GPU 设计公司，但能生产最先进芯片的晶圆厂是稀缺中的稀缺"。若 18A→14A 跑通并拿到大量外部客户，即成为"全球先进逻辑制造双极之一"。**三个观察点：①生产良率 ②外部客户订单 ③玻璃基板进度**
2. **CPU + ASIC**——服务不想完全依赖 NVIDIA 的 Hyperscaler
3. **PC / Edge / Physical AI**——定位为**防守**（Apple/Qualcomm/AMD/NVIDIA/ARM 全在里面，"没有一个弱者"）

## 四、与模型的矛盾点 / 本篇的自我削弱

### ⚠️⚠️ 1. 循环论证：用现价倒推 PS，再拿这个 PS 宣布现价合理

"用现在 100 美元的价格来倒推一下，现在市场计价了多少。Q2 整个 Foundry 58 亿收入，相当于年化 232 亿……再给他一个 10 倍 PS……大概就是 2320 亿，**差不多就是现在的股价**。"

倒推得到的 2320 亿本来就是从市值算出来的，它当然等于市值。**这一步没有产生任何独立信息**。全段真正的判断只有一句——"10 倍 PS 大概就是特斯拉市梦率的水平，现在的计价已经把很多的希望打满了，没有太多容错空间"。他随后自己承认"要给其业务进行一个模糊的正确估值，好像我也还没有很好的方法"。**这是本篇的诚实处，但账本必须记：Foundry 一节没有估值，只有一个态度。**

### ⚠️⚠️ 2. 同一分部内混用两种年化口径，各取有利的一端

DCAI 给 15–18× PE：
- 用 **H1 年化**（40.16×2＝80.32 亿）→ 1205–1446 亿
- 用 **Q2 年化**（24.74×4＝98.96 亿）→ 1484–1781 亿

他给出的区间是 **1200–1800 亿**＝**下沿取 H1 口径、上沿取 Q2 口径**。CCPG 同样：H1 年化 97.18 亿 ×9–13＝875–1263 亿，他给 1000–1300 亿，**下沿高出约 14%**。

这与 #183（谷歌篇）记录的"**每一处有区间的地方都取在中点之上**"是同一漂移的**新变体**——那次是取值偏上沿，这次是**换口径**。⭐但需公平记录一个反例：本篇的中性值 2600–2700 亿恰是 2200–3100 的中点（2650），**这一步没有漂移**，而谷歌篇的中性值是上沿。**漂移发生在分部层，不发生在汇总层**——这个更精确的判据可以带进 M9。

### ⚠️⚠️ 3. 他自己点出却没往下算的数字：94.9% 的内部关联交易

2.93 ÷ 57.65 ＝ **5.08%**。Foundry 收入里 **94.9% 是卖给自家 Products 的内部转移定价**。他两次擦过这个事实（"这还是外部业务仅有 2 亿的情况下""也不区分内外了"），然后照样对整个 58 亿给 10 倍 PS。**若只给外部收入计价，年化约 11.7 亿，10 倍 PS＝117 亿——与 2320 亿差 20 倍。** 这是全篇信息量最大的一处，也是路径 A/B 分叉的唯一定量抓手。

### ⚠️ 4. 原则 7 的第 4 次执行，第 3 种做法

"没有现金流的期权统统是零"在本库已出现三次不同处理：

| 出处 | 标的 | 现金流状态 | 他的处理 |
| --- | --- | --- | --- |
| #174/#178 | 京东方玻璃基板 | 无收入无现金流 | **给正值**，并做了时序 |
| #183 | 谷歌 Waymo 及其他 | 无收入无现金流 | **给 0**，一句话带过 |
| **本篇** | Intel Foundry | 有收入、持续亏损 | **不给零也不自估**，承认"市场已经给了一张期权估价"，然后拒绝下手 |

**判据始终未言明。** 这是 M8 之后第二次同类冲突（首次为 #183 vs #174）。📌**标记待 M9 模型刷新时正式处理**：原则 7 需要一条"什么情况下期权可以不为零"的成文边界，否则它在实践中只是"看好就给、不看好就零"的事后合理化。

### ⚠️ 5. 两处系统性缺席

- **政府这一变量全程定性**：只有"美国政府巨额补贴""由美国国家信用贴现的一张战略牌"，**没有一个数字**——补贴金额、股权稀释、附加条件全部缺席。对一个他自己定义为"由国家信用支撑"的标的，最关键的估值变量没有进入任何一个算式。
- **三星缺席**：Foundry 一节写"打不过 TSMC 和三星"，但全篇无一句三星代工的现状数据。他的对标是二极（Intel vs TSMC），产业实际是三极。这与 M8 盲区第 9 项"竞争格局是系统性盲点"同源，**连续第三篇出现**。

## 六、反方视角

**本篇最可能错在把"结构上可能吃到贝塔"当成了"能吃到贝塔"。** 开放阵营的存在是真的（Google TPU、OpenAI 自研芯片都在），但阵营需要的是**便宜可靠的通用件**，而 Intel 在这条路上的对手是 AMD（同样卖 x86 CPU、同样卖 GPU、Foundry 成本却外包给 TSMC，没有 Fab 折旧负担）与 ARM 阵营。"所有关键层都有它"在买方眼里也可以读成"每一层都有更好的选择"——**IDM 的一体化在良率不达标时是负债而非资产**，Products 的利润会持续被 Foundry 抽走（这正是他自己写的路径 B）。

另一个反方：他给的"不下手"结论**建立在一个他承认自己没有方法估的分部上**。当 60% 的隐含市值（2300–2500 亿 / 5000 亿）落在一个自认无法估值的业务里，"贵"和"便宜"都不是可靠判断——**诚实的表述应是"无法定价，故不下注"，而不是"计价已经把希望打满了"**。这两句话的证据强度差很多。
