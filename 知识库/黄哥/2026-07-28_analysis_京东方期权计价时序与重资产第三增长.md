# 京东方期权计价时序与重资产第三增长

来源：260728关于京东方的逻辑猜想   .pdf  
分析时间：2026-07-29 | 核心判断/核心洞察：本篇把原则7「期权=0」从一个**二元开关**升级成**四段计价时间轴**（研发→认证通过=开始计价→小批量供货→现金流），并给出重资产企业被忽略的第三条增长曲线——不是多卖，而是**停止扩产**；结论仍是"2026-07-28 京东方的期权价格是零"

## 一、核心判断（一行版）

京东方的价值 = 一家靠「出货面积 × 每平方米价格 × 产品结构」吃饭的重资产面板厂（占收入 81%），三条增长路（多卖·卖贵·落袋）分别是难·很难·非常难；玻璃基板给了它从显示业跨进先进封装的**可能性**，但"能力能迁移 ≠ 商业模式跑通 ≠ 现金流形成"，所以在认证通过之前，这份期权按芒格的标准**估值就是零**。

## 二、三栏增量

### A. 新增原则/工具

**1. ⭐期权计价四段时间轴（原则 7 的操作化升级，本篇最大增量）**

模型里原则 7 一直是个二元开关："期权价值在变成钱之前 = 0"。本篇第一次给出**什么时候开关翻转**：

```
研发 → 调试 → 认证【← 计价起点：通过认证、具备生成订单的能力】
    → 小批量供货【← 产生现金流】→ 大规模量产【← 计入正常估值】
```

原文："什么时候开始给其计价？等认证通过了，具备了生成订单的能力再开始记入期权价格。而后才是小批量供货，产生现金流。"

这解决了原则 7 长期的操作困境：二元开关在实践中不可用（现金流跑通那天股价早已涨完），而"认证通过 = 计价起点"是一个**可公告、可日期化、可提前布防**的观测点。建议下次刷新正式并入原则 7，与三章 A「四步兑现范式」的第一断层（技术确定性→需求刚性）对接——本质上四步兑现范式讲的是"从技术到业绩"，这条时间轴讲的是"从技术到计价"，两者共用同一根轴。

**2. ⭐重资产企业的第三增长曲线：停止扩产（不是开源，是节流）**

原文给出的三分法：销量增长 / 产品结构增长（利润）/ **自由现金流增长**。第三条是新东西，且被数字钉死：

> 2025 年经营现金流 488 亿 − 资本开支 400 亿 = 自由现金流 **88 亿**  
> 若行业不再大规模扩产，资本开支 400 亿 → 250 亿，经营现金流不变，自由现金流 88 亿 → **238 亿**（+170%）

一句话总结："如果京东方从一台不停扩产的机器变成吐出稳定现金流的机器，那么其增长不亚于多做了几百亿生意。"

这是**算力资本化（v3.1）的镜像**：英伟达那条讲的是资本开支膨胀如何把利润表变成资产负债表游戏；这条讲的是资本开支收缩如何把资产负债表游戏变回现金流。两条应合并成同一个工具——"资本开支方向盘"，对任何重资产标的都问一句：**这家公司的下一个增长点，是多花钱还是少花钱？**

**3. 通用商业公式的行业改写法（方法论层）**

"营业 = 流量 × 成交率 × 客单价" → 面板版："**显示收入 = 出货面积 × 每平方米价格 × 产品结构**"；配套利润式："**利润 = 出货面积 × 单位面积利润 − 折旧 − 研发 − 期间费用 − 减值损失**"，并收敛为**六变量监测器**：价格 / 面积 / 产品结构 / 稼动率 / 良率 / 折旧。

这是他第二次做同类动作（第一次是溜溜梅的消费品定价五步公式）。可提炼为可迁移方法：**看不懂一个重资产行业时，先把通用商业公式改写成该行业的物理量纲**（面积、片、吨、机时），再逐项问"哪一项在变"。

**4. OLED 的五级验证链（高端化叙事的证伪器）**

出货量增长 → 高端产品占比提高 → 良率提升 → 单位成本下降 → 毛利率改善 → **最终形成现金流**。判据锋利：**"如果 OLED 出货量不断增长，但利润和现金流没有同步增长，那就说明公司在用资本开支换取市场份额。"** 因此 OLED 对京东方"既可能成为利润来源，也可能继续成为资金黑洞"——这是把"高端化 = 好"的默认叙事拆成一条有明确断点的链。良率的量化直觉也给得很好：一百块只有六十块合格，剩下四十块的材料人工设备折旧要由那六十块承担。

### B. 强化/修正的已有原则

- **原则 7（期权 = 0）**：本篇是模型建立以来最直白的一次自我执行——面对市场刚开始热炒的题材，明确写下"**所以到今天，2026 年的 7 月 28 日，京东方的期权价格还是零**"。与 v3.2 里张江高科证伪样本同构，属于"国产替代叙事通用证伪器"的第二个样本。
- **原则 3（排除法）**：三条增长路逐一判"难 / 很难 / 非常难"，第四条（玻璃基板）判"十分困难"，全篇没有一条是"好"。排除法这次用在了**同一家公司的内部路径**上，而非跨标的比较。
- **#163「京东方 2.0」的机制自洽**：7-10 那篇把面板定性为"固定资产、产线长寿命"（对照存储的跑步机），本篇第三种增长恰恰建立在这一性质上——**正因为产线长寿命，才谈得上"停止扩产而现金流不塌"**。两篇互为支撑，不是矛盾。
- **原则 8（基本面只是入场券）**：2025 年 TFT-LCD 销售面积 +8.3%、AMOLED +8.2%，而显示器件收入仅 +0.9%；整体毛利率 15.6%、显示器件 12.9%。"面积明显增加但收入几乎没有同步增长"——量的增长不构成价值，第 N 次实证。

### C. 与模型的矛盾点/张力

1. **⚠️玻璃基板量产时间表被自己后移了约一年**。本篇："全球顶尖的晶圆厂也要在 **27 年底或者 28 年**才开始逐步量产。"而预测表 **#17（2026-06-17）**记的是"玻璃基板量产里程碑在 **2026-2027** 年形成（英特尔 / SKC 首批量产客户公布）"。同一信源一个半月内把时间轴推后一档。**这不是错误，是有价值的信号**：说明他 6 月的时间表偏乐观，且 6 月那批海外三级标的（P0 Onto+LPKF / P1 SKC+SamsungEM / P2 MKS+SUSS）的兑现窗口应同步顺延。已作为进度证据回注 #17。

2. **⚠️A 股 / 海外双标未被自觉**。对海外玻璃基板标的（#141/#146/F3），他愿意在无量产、无现金流的阶段给出"铲中铲 > 平台 > 中后段"的可交易优先级；对京东方，他要求"认证通过才开始计价"。两者处在同一产业的同一阶段，标准却不同。合理的解释是海外标的是设备/材料（有现成的显示业务现金流做安全垫），京东方是**新赛道的代工方**——但原文没做这个区分，这个双标目前是隐性的。

3. **⚠️竞争格局全篇缺席**。"京东方作为全球最大的面板厂……就必须要进入视野了"是一次**从规模直接跳到资格**的推理。玻璃基板赛道上康宁、AGC、日本电气硝子、SKC/Absolics，以及国内 TCL 华星、彩虹股份、沃格光电，一个都没出现。"为什么是京东方而不是华星"这一步没论证——而这恰恰是四步兑现范式第一断层（技术确定性）最该盘的东西。

4. **⚠️折旧只走了一条腿**。折旧被写进利润公式当纯扣减项，但重资产行业最经典的利润释放机制是**折旧到期红利**（产线跑满会计年限后，同样的出货面积吐出显著更高的利润）。这和他自己第三种增长的"资本开支下降"是同一根逻辑的两条腿，本篇只走了资本开支这条。

5. **⚠️减值损失入了公式但全文零展开**。这是面板周期股最大的一次性变量，且京东方历史上多次大额计提。写进公式却不给观测方法，属于**列而不测**。

6. **⚠️"先有价格后有认知"第二次出现（行为模式，非单篇问题）**。原文自问："为什么市场突然开始关注京东方？"——写作触发点是市场热度，与 #173 商业航天（在 SpaceX 上市催化与国产首回收之后才建认知）完全同款。**两次连续出现，应从单篇警示升级为对信源的稳定行为特征记录**：他的**选题**由市场热点驱动，但**结论**常与热点相反（航天篇不给标的、本篇明说期权价格为零）。这是一个有利的组合——被动选题 + 主动泼冷水——但意味着"他开始写某赛道"本身不是买入信号，反而更接近"该赛道已经涨过"的滞后指示器。

7. **⚠️估值框架欠账（原文自认）**。第五节只留下三条要求：①匹配重资产高折旧 ②匹配周期性经营 ③针对其扣非现金流具备交叉验证性。**未完成状态本身是罕见样本**——第 0 层总纲讲"消费者买结论、生产者生产结论"，这篇把生产过程的卡壳点公开了，属于总纲的第一人称正面样本（继 #173 之后第二次）。待下篇（预告"明天继续"）补齐后再做合并。

## 四、反方视角

**本篇最可能错的地方，是把"期权价格 = 零"当成了一个估值结论，而它其实是一个仓位借口。**

原则 7 在这里被执行得很漂亮，但它有个结构性副作用：**当一个题材真正跑通时，"认证通过"公告日往往就是股价的最后一段，而不是起点**——认证的信息在产业链里提前数月扩散，等到公告，先知先觉的资金已完成建仓。他自己在 v3.2 的失效场景里已经写明"长期高估值市场系统性踏空"，本篇正是这个失效模式在 A 股题材股上的翻版：一个把叙事权重清零的系统，在**叙事就是这轮行情全部内容**的市场里，会永远站在场外并且永远正确。

更尖锐的一点：**第三种增长（停止扩产）在面板行业从未真实发生过**。韩厂退出后大陆继续扩，大陆产能出清后又有印度、又有新一轮世代线。把资本开支从 400 亿降到 250 亿是个算术假设，不是产业规律——而全篇最亮眼的那个"88 亿 → 238 亿"，恰恰完全建立在这个未经论证的假设上。真正该问的不是"如果资本开支下降会怎样"，而是"**这个行业里，谁曾经真的停下来过**"。
