# 阿斯麦"汽车品牌商"模型与五层光刻产业链

来源：260716阿斯麦的财报，可以当汽车品牌商来看，既卖新车也卖老车，还修旧车.pdf
分析时间：2026-07-17 | 核心判断：市场盯着 EUV 订单，但撑住这一季阿斯麦的是 **DUV + 老设备升级**——把 ASML 财报当作"全球晶圆厂资本开支的订单地图"来读，读出三个信号：①存储厂前端扩产坐实（存储占设备收入从 25Q4 的 30% 跃至 26 年两季的约 50%），存储周期未结束；②DUV 不被 EUV 替代、反而跟随 EUV 增长，AI 基建仍在扩张（ASML 计划 2027 产能 +30%、研究 2028 再 +30%）；③"修旧车"（存量设备维保升级）正在长成一条不性感但高确定性、高毛利的独立赛道。

## 一、这是什么

**⭐ 元层面先说**：这篇是前一天 [260714 元二分](2026-07-14_analysis_消费者买结论与生产者生产认知的元二分.md)的**现场演示**。消费者看 ASML 财报看"营收超预期没、股价涨没涨"；黄哥的读法是把财报当**上游情报**——"谁在扩产、扩什么产、缺哪类设备、是买新机器还是拼命升级旧机器"。同一份公开文件，消费者读出结论，生产者读出订单地图。理论篇与实操篇隔天连发，可视作一组。

**核心类比（本篇标题即模型）**：ASML = 汽车品牌商
- **卖新车** = Low-NA EUV（当前利润与订单主力，2nm 逻辑/先进 DRAM 量产核心）
- **卖老车** = DUV（KrF / ArF 干式 / ArF 浸没式，其中浸没式价值量最高）
- **修旧车** = 存量设备管理（维保、软件、升级、备件、现场服务）
- **概念车（期权）** = High-NA EUV（孔径 0.33→0.55，更好更贵更远）

商业模式一句话：**卖设备建立装机量，再靠维修、软件和升级持续收费**。

**关键结构数据（2026 Q1→Q2，亿欧元）**：

| 板块 | 26Q1 | 26Q2 | 环比 |
|---|---|---|---|
| 设备总收入 | 63 | 66 | +4.8% |
| 　其中 EUV | 41 | **38** | **-7.3%** |
| 　其中非 EUV(DUV) | 21 | **28** | **+33.3%** |
| 存量设备管理 | 25 | **28** | **+12.0%** |
| 总营收 | 88 | 94 | +6.8% |

客户结构：逻辑/存储占比 25Q4 **70/30** → 26Q1 **49/51** → 26Q2 **51/49**。

**读出的两件事**：①DUV 需求明显增长——AI 服务器不只有 GPU/先进 CPU，还有 NAND、DRAM、电源芯片等成熟配套，EUV 只留给最先进制程，**DUV 反而跟随 EUV 的增长而增长**；②客户在榨取现有设备产能——存量管理收入超预期且毛利不低，即**新机扩产与存量升级同时发生**。

## 二、三栏增量

### 新增原则 / 框架

- **⭐"卖新车/卖老车/修旧车"设备商三段收入模型**：给设备类公司一把通用解剖刀——把收入拆成新机(前沿) / 新机(成熟) / 存量服务三段，分别对应不同的周期属性与确定性。核心洞察是**装机量是存量服务的蓄水池**："只要是车总是要修的，新车卖得越多、用得越久，修车保养频次越高"。这条可直接迁移到任何"设备+服务"生意（半导体设备、医疗器械、工程机械、电梯）。
- **⭐财报=上游订单地图（读法升级）**：不把财报当业绩考卷，当**别人家资本开支的侦察卫星**。ASML 的客户结构变化直接反证"存储厂真的在扩产"——用 A 公司的财报去验证 B 行业的景气，是四步兑现范式（逻辑→订单→财报）的**交叉验证版**：不等自己标的的财报，先读它上游供应商的财报。
- **五层光刻产业链图谱（本篇主干）**：
  1. **整机及核心系统**：ASML(EUV+高端DUV) / Nikon(DUV) / Canon(成熟制程+纳米压印) / 上海微电子(国产路线)。→ *受益最直接，但确定性最容易被市场提前定价*（= 好投资四好里"price 已打满"的风险位）
  2. **光源、光学与精密运动**：光源 / 镜头反射镜（蔡司长期独供：DUV 用透镜、EUV 用反射镜）/ 掩膜台晶圆台 / 精密运动控制 / 激光传感器执行器。→ ⭐**择股判据：横跨 Low-NA EUV 与 DUV 的通用核心零部件，确定性高于单押 High-NA**
  3. **真空、温控、减振、污染控制**：真空泵阀 / 尾气处理 / 精密温控 / 减振平台 / 过滤 / 高纯流体输送。→ 同时吃"新设备出货 + 已安装设备存量 + 维修备件"三份需求，**既是卖铲业务，也是卖水业务**（铲子框架的升级形态）
  4. **光刻材料**：EUV/ArF/KrF 光刻胶、掩膜版及基板、Pellicle、显影液清洗液。→ ⭐计价基准切换：**受益于晶圆产量和曝光次数，而非光刻机出货量**
  5. **量测、检测与计算光刻**：套刻测量 / 缺陷检测 / 掩膜检测 / 电子束检测 / OPC 计算光刻软件。→ ⭐**制程越复杂，测量修正次数越多 → 增长弹性甚至高于晶圆产量**（全链弹性最高位）
- **"卖铲 × 卖水"二分**：第三层被点名为两者兼具——卖铲=随新设备出货一次性收入，卖水=随装机存量持续消耗。这是对既有铲子框架（260604 五层优先级）的**维度扩充**：铲子有一次性和耗材两种现金流形态，后者更像年金。

### 强化 / 修正的已有原则

- **强化"存储周期未结束"（推演一，与 260710 呼应）**：存储收入连续两季占设备收入近半 = 存储厂在加大**前端**投入。→ 由此提出 **HBM 机会不能只看后道封装，要向前看**：DRAM 晶圆产能 / EUV·DUV 光刻 / 刻蚀沉积 / 掩膜版 / 光刻胶 / 量测检测。这是对此前"HBM 看封装"叙事的自我扩展，方向上与 260710《存储vs面板》的"存储是永不停歇的跑步机"一致。
- **强化"期权未兑现即为 0"（芒格纪律，用于张江高科泼冷水）**：黄哥点名更新张江高科——主营是园区运营+产业投资，持上海微电子仅 **10.8%**，自身盘子已 500 亿。两层问题：①上海微电子订单利润**何时**兑现、能兑现**多少**；②兑现额 ×10.8% 对 500 亿盘子的**弹性**有多大。结论按芒格"没兑现的期权价值就是 0"——**买张江高科实为给园区运营和繁杂产业投资支付高昂溢价**。这是"国产替代期权"叙事的标准证伪模板：*不控股 + 份额小 + 母体盘子大 = 弹性被稀释掉*。
- **强化 High-NA = 远期期权而非当期主线（推演四）**：Q2 的 38 亿欧元 EUV 收入中**只含一台 High-NA**。与 260604 材料三角、260622 InP 一样，黄哥反复把"技术上最先进"与"当期能赚钱"分开摆——技术前沿 ≠ 投资主线。
- **强化物理瓶颈论**：EUV 不替代 DUV，因为二者分工由物理决定（EUV 只做最关键最精细的层，其余曝光层仍由 DUV 承担）——技术代际是**叠加**而非**替代**，这与 800V、封装代际跃迁的推理骨架同构。

### 与模型的矛盾点 / 张力

- **⚠️数据自相矛盾（需标注）**：正文写"总收入从 88 亿欧元增加到 **93** 亿欧元"，但同页表格为 **94**；且 Q1 设备总收入 63 ≠ EUV 41 + 非EUV 21 = 62。属于口径/四舍五入瑕疵，不影响趋势结论，但提醒**引用本篇具体数字前需回原始财报核对**——这恰是本篇自身"要做生产者、别买加工过的结论"的反讽。
- **"存储占比趋势性上升"的表述略过度**：26Q1 存储 51% → 26Q2 **49%**，环比其实是**回落**的。黄哥用"26 年两个季度的 50%"把两季抹平成一个平台再对比 25Q4 的 30%——结论（存储扩产坐实）成立，但"趋势性变化"的措辞掩盖了 Q2 已见平甚至微降，若 Q3 继续回落则叙事需要修正。
- **EUV 收入环比 -7.3% 被轻轻带过**：全篇的乐观基调建立在 DUV + 存量服务上，但 EUV 作为"利润主力"环比下滑 7.3% 这件事，黄哥只解释为"结构很有意思"，没有追问是**交付节奏波动**还是**先进制程扩产放缓**。若是后者，则"AI 基建还在扩张"的结论根基会松动——这是本篇最该挖第五层却停在第三层的地方。
- **无标的、无价格**：五层图谱只到"哪层弹性高"，没给具体公司、更没给估值判断（唯一给价格判断的张江高科是负面的）。按其自身"产业+公司+价格"三重理解标准，本篇只完成了三分之一，需等预告的"产业链玩家"下篇才闭环。

## 四、对抗步骤（反方视角）

1. **"DUV 强 = AI 基建扩张"可能是倒果为因**：非 EUV 环比 +33% 更可能来自**中国成熟制程抢装**（出口管制窗口期抢购）和存储厂的低世代扩产，而非 AI 拉动。若真相是"中国抢货"，那这笔收入是**一次性透支**而非可持续增长，2027 产能 +30% 反而会撞上需求空窗——黄哥把 DUV 增长直接归因于 AI 配套芯片，缺少对地缘抢装因素的排除，这是本篇最大的归因风险。
2. **"修旧车高毛利"的另一面是新车卖不动的前兆**：设备商的存量服务占比上升，在周期顶部往往不是好消息——客户"榨取现有设备产能"恰恰意味着他们**不愿意/不敢下新机订单**。同一组数据可以读成"确定性收入增强"，也可以读成"资本开支见顶、客户转向省钱模式"。黄哥选了前一种解释，但没有给出排除后一种的判据。
3. **五层图谱越往下越"弹性高"，可能是幻觉**：说量测检测"弹性甚至高于晶圆产量"听着诱人，但这一层被 KLA、ASML(YieldStar)、AMAT 等寡头垄断，A 股可参与标的的实际份额与技术代际都极低。弹性属于**这个环节**，不等于弹性属于**你能买到的公司**——这正是他自己批张江高科时用的逻辑（份额小则弹性被稀释），本篇在讲第四、五层时却没对自己的图谱做同样的拷问。
