## 第0层 · 总纲：消费者 ↔ 生产者元二分（来源 260714/260715，v4.0 保留最高层）

> 这一层凌驾于下面所有原则、工具之上。**本模型的全部内容，本质都是"如何成为认知的生产者而非消费者"的操作分解。** 若只记一件事，记这个轴。

- **元轴定义**：绝大多数人（消费者）站在信息链的**末端**，买的是被层层加工好的**结论**——到手时只剩"涨/跌"两个数字。少数人（生产者）逆着信息链 `原材料 → 产能 → 订单 → 收入 → 利润 → 估值` 往上游挖 4-5 层，自己**生产认知**。
- **核心能力 = 生产认知 ≠ 预测市场**：赚的不是"猜对涨跌"的钱，是"比别人早、比别人深地看懂产业结构"的钱。（⚠️ 内在张力：一边背书 EMH 一边持续给可证伪预测，见盲区7）
- **⭐v4.0 新增落点：生产认知的第一步是生产问题**（260805）。面对"Gemini 能给谷歌创造多少新收入"，他的第一反应是**这个问题问错了**——消费者接手被加工好的问题，生产者先拆业务底座再决定该问什么。**"提问方式"本身就是消费者/生产者的判别点。**
- **与四步兑现同链两向**：第0层 `原材料→…→估值` 与三章「四步兑现范式」是同一条产业链的两个方向——顺流预判（买之前）/ 逆流生产（验证之中）。
- **三重理解缺一不可**：产业 + 公司 + 价格。好公司若价格已 price in 五年增长，买入照样亏。
- **职业 = 被低估的一手信息资产**（260715）：**职业雷达四扫描项**：①行业里什么在结构性变化 ②哪些是只有内部人才知道的一手信号 ③信号在信息链的哪一层（越上游越值钱）④多久传导到价格。**三能力检查表**：能看到 / 能看懂 / 能押注。
- **⭐信息优势的"刹车价值"**：一手信息最大的用途常常不是让你"买对"，而是让你**不买**——**让你不买 = 财富保险**。与原则9"少决策"、原则3"排除法"同源。
- **⭐有效认知乘法公式**：`最终收益 ≈ 看得早 × 看得对 × 押得准 × 活得久`（任一项为 0 则整体归零）。
- **⚠️ v4.0 记录的反面样本**：0804 宏发中报中，他验证"备产还是滞销"这一关键分叉用的是**论坛信息**（"根据目前论坛信息得到宏发厂里订单饱满"）。论坛正是"消费者买结论"的集散地。**对陌生赛道要一手数据，对自己持仓接受二手情绪**——总纲在自己持仓上会降级，这是第0层最值得记的失效条件。

**推荐书**：《制造消费者》。

## 一、认知核心原则（11 条）

### 原则 1：识别结构性矛盾，而非表象
- **机制**：系统根因 > 政策应对；历史周期 > 短期波动
- **失效条件**：极限冲击（战争/政变）下历史周期参考失效
- **案例**：房地产本质是人口周期；养老"需求存在但支付能力缺失"

### 原则 2：利益结构决定立场
- **机制**：经济激励 > 言论承诺；钱从哪来，就往哪转身
- **案例**：石油君主国明合作暗结盟；茅台逻辑在"权力收益渠道"的永续性
- **⭐M9 制度下沉（260818）**：地方权力的支持来源决定其"向上看还是向下看"，进而影响民营企业容错、企业密度与居民分配渠道。可执行追问：权力支持函数是什么、失败成本谁承担、增长收益经哪条水路到居民？⚠️四省横截面只能支持相关，不能单独识别因果。
- **⚠️ v4.0 缺口记录**：0805 谷歌篇写 AI agent "帮你比较方案然后完成行动"，同时点明"**这个建议是来自于某个广告商的**"——顾问与广告商双重身份的利益冲突正是本原则的主场，他却把它当正面卖点带过。**原则 2 未被用在自己看好的公司上。**

### 原则 3：排除法比正向法更可靠
- **机制**：先定义坏生意/坏标的，剩下的就是相对安全的
- **三次升级**：①选标的（淘汰五类）②**选环节**（"火箭只是搬运工"，260730）③**选需求**（"太空不是目的只是解决方案"，260727）→ 通用判据：**贵方案必须先证明便宜方案的失效边界**
- **④选内部路径**（260728 京东方）：对同一家公司的三条增长路分别判"难/很难/非常难"

### 原则 4：时间精确度是竞争力
- **机制**：周期长度、拐点、节点的精确匹配 = 买卖时间窗口
- **⚠️ 自我违反样本**：把 SpaceX 已验证的美国成本曲线套国产链（260727）

### 原则 5：制度溢价具有永续性但极脆弱
- **机制**：权力结构 = 现金流来源；结构变化 = 溢价瞬间瓦解
- **A股边界前置条件（260723）**：**"带闸门的水库"**——入库/出库闸门 + 统一监管 = 政策资金可控性的前提；无闸门则政策有效性判断不成立
- **⭐M9 从资产定价扩展到生产组织（260818）**：制度不仅给资产现金流定价，也决定生产者能否繁殖。新增链条：`权力支持来源→地方行为→失败容忍→企业密度质量→产业繁殖率→居民分配接口`。企业在册数只是中介变量，必须继续看活跃率、存活率、就业与经营净收入。

### 原则 6：存量竞争中，独立性等于生命力
- **机制**：平台依赖 = 命运在他人手中
- **平台侧视角（260805）**：Mr.Beast"**寄生**在 YouTube 上获取注意力"——同一机制从平台一方写

### 原则 7：期权价值在变成钱之前 = 0 ⭐v4.0 大幅升级
- **机制**：任何未兑现为利润的增长预期、转型故事、潜在市场，一律不计入估值
- **代价（他自己承认）**：系统性错过早期成长股
- **⭐A · 从二元开关升级为「期权计价四段时间轴」**（260728/0730）：
  `研发 → 调试 → 正式认证 → ⭐小规模订单出现（= 计价起点） → 稳定良率 → 大规模出货 → 量产利润 → 自由现金流`
  - 解决了原则 7 的操作困境（"现金流跑通那天股价已涨完"）：不必等现金流，但也不能在认证前给价。
  - ⚠️**计价起点两天内被自己后移**（0728 定在"认证通过"，0730 改为"小规模订单出现"）——起点不稳定，引用时须注明版本。
- **⭐B · 新增正向条款「向内生长 vs 向外生长」**（260805）：期权=0 不等于新技术无价值，而是**要到旧报表里去找它的价值**。
  | | 向外生长 | 向内生长 |
  |---|---|---|
  | 形态 | 新业务、新收入线 | 存量业务每个环节的效率提升 |
  | 提问方式 | "AI 能创造多少新收入？" | "AI 让老业务效率提高多少？" |
  | 财报表现 | 新分部收入 | 老分部量/价/周转/**资产生命周期**同时改善 |
  - 谷歌样本：AI 对 YouTube = 提高生产效率 → 打破语言限制 → 扩大供给 → 提高推荐精度 → **延长优质内容生命周期**（资产端而非收入端）。
  - ⚠️**反例边界（必须绑定）**：向内生长在财报上无独立科目，因而**天然难证伪**（涨了叫 AI 提效，没涨叫"AI 顶住了本来会掉的"）。使用前必须先回答："如果这个判断是错的，我会在哪个数字上先看到？"
- **⭐C · 弹性检验＝原则 7 的量化版**（260803，见三章断层③）：新增量 ÷ 现有收入 < 5% = **叙事型受益，逻辑再对也不构成买入理由**。
- **⭐D · M9 统一期权证据门（260814/0820）**：解决京东方给正、Waymo 给零、Intel 用现价倒推、禾望用传闻计价等多版本冲突。
  - 送样/产业传闻 = **0**；
  - 正式认证 + 小批量 = **情景备忘录，不进主价值**；
  - 公告订单 + 可测收入 = **概率计价**；
  - 连续收入 + 毛利率/现金流 = **移入成长分部**。
  - **证据—倍数同向纪律**：证据越弱，折现越重；禁止“底座 18×、传闻期权 40×”而无额外概率折扣。语言评级同样受门约束——“未来三年好公司”也是隐含计价，不能绕门。
- **两个已确认例外**：
  - **黄金/主权信用类宏观资产**：主权信用走薄的保险，不适合"期权=0"逻辑
  - **"Win or Go Home"军备竞赛场景**：M7 CapEx > 经营现金流（GOOG 1800B > 1740B）时，出局成本 > 亏损成本；须监测资本容忍度拐点三指标（单位 CapEx 产出效率/指引措辞/上游订单）
  - **⚠️ 自融资红线（260706）**：CapEx 靠**供应商融资**维持时（设备商给客户融资/担保），信号是"真实需求已不足以支撑当前销售规模"，例外应向"泡沫"一侧收敛。**第四信号=自融资比例**
- **两个证伪器样本**：张江高科（持上海微电子 10.8% 不控股 = 国产替代叙事通用证伪器）；京东方（"到今天 2026-07-28 期权价格还是零"，最直白的一次公开自我执行）
- **⚠️ 自我违反样本（260803 宏发）**：期权清单被判 0 一次，又从成长倍数 22-25× 里计价了一次（该倍数的理由"高价值产品占比提升"指向的正是那批被判 0 的期权）。

### 原则 8：基本面只是入场券，不是胜利保证
- **机制**：还有外部环境（政策/情绪/宏观周期）与情绪免疫力；"我明明做对了"是忽视这一层的标准败因
- **工具**：仓位三角 + 噪音六问 + 回撤处置四步链（见四章）

### 原则 9：少决策、大押注、快纠错
- **机制**：收益分布极不均匀（~90%收益来自~10%决策）
- **三条铁律**：衰退行业禁入；友人推荐不是投资理由；发现错了立即脱手
- **⚠️ 边界补丁（260708）**："立即脱手"针对**已确认的认知错误**，不是**价格下跌**。逻辑没坏还拿=坚持；逻辑坏了还拿=用时间掩盖错误
- **⚠️ 未解冲突（260724）**：新增铁律"**负面情绪出现时不做决定**"与"发现错了立即脱手"在"确认错误=情绪最差"这同一时点给出相反指令，且**未给情绪退潮的时长边界**——易沦为其自批的"用时间掩盖错误"。引用时须自行设定退潮期。
- **失效条件**：系统性恐慌底部，"少决策"可能变成"错过底部"

### 原则 10：时间差原则——叙事、技术、现金流之间的 Gap 是泡沫之源
- **机制**：叙事确定性先行 → 技术兑现滞后 → 现金流兑现更滞后；Gap 越大泡沫越大
- **监测变量**：资本开支流速 vs 下游现金流加速度
- **v4.0 新样本（260805 谷歌）**：技术兑现已到（AI Mode 10 亿 MAU），现金流兑现未到（"接下来我们需要看到……广告主愿意为 AI 付费"）——Gap 仍开着

### 原则 11：好投资四好——技术面正式纳入时机判断
- **框架**：好公司 × 好价格 × 好时机 × 好仓位
- **核心转变**："技术面就是资金站哪边的显示器"
- **亏损四分法**：基本面变了/估值错了/技术情绪/仓位管理，处置截然不同

## 二、决策流程模型（可执行）

```
[输入：标的/事件/政策]
    ↓
STEP A · 信息压缩：历史对标？利益结构？结构矛盾？
    ↓
STEP B · 看懂检验：能否用常识一句话给8岁孩子讲清楚？不能→放弃
    ↓
STEP C · 双重压力测试
  ├─ 芒格三问（看死法）：怎么死？没了有影响吗？十年后还在吗？
  ├─ 李录五问（看活法）：赛道值得吗？顺势还是借势？结构性钱还是已赚到的钱？
  │   市场关五年敢持有吗？能力圈内吗？
  └─ 硬性排除：管理层利益不对齐
    ↓
STEP D · 定价 → 见三章 C「估值三件套」
    ↓
STEP E · 仓位三角：进场时间 × 持有时间 × 仓位大小，三者同时合理才动手
    ↓
STEP F · 持仓监控
  ├─ 噪音六问：买入理由变了吗？基本面变了吗？估值还合理吗？
  │   仓位过重吗？继续跌能承受吗？现在加仓是理性还是情绪反击？
  └─ 撤离信号独立于买入逻辑：预设具体撤离条件，触发即执行
```

**情绪规则**：情绪只可用于观察（当市场状态信号读），不可用于决策（当行动指令执行）。

## 三、选股 · 验证 · 定价三段流水线

> **v4.0 减法说明**：M7 的"双向流水线"（A 顺流/B 逆流）保留；原先散落在"配套工具"里的产业链拆解手法（阿斯麦五层、航天五层、八问链、两线交叉、甜点位）**合并为下方统一模板**，不再分列；新增 C 段补上模型此前最大的缺口——**定价**。

### A · 顺流预判：技术→业绩四步兑现范式（260704）
```
技术确定性 → 需求刚性 → 订单兑现 → 财务确认
 断层① 技术会发展 ≠ 某产品受益
 断层② 产品被用   ≠ 某公司拿单（客户入口七阶段：关系→送样→认证→定点→小批→批量）
 断层③ 拿到订单   ≠ 规模足以改变利润   ⭐见下方"弹性检验"
 断层④ 利润增长   ≠ 股价仍有空间
```
- **⭐断层③ 弹性检验（260803 并入）**：`新增量 ÷ 现有收入 < 5% = 叙事型受益`。宏发样本：800V 即便拿 40% 份额也只有 2-4 亿，对全年近 200 亿收入"基本没有弹性"→**方向对了，但理由不一定**。这是他首次用自己的尺子推翻自己的买入理由，也是全模型最锋利的一把去叙事工具。
- **⭐断层② 认证＝买时间（260803）**：认证的价值不是技术背书，而是"**为公司购买了进入客户未来产品的时间和测试机会**"→ 平台化扩张的评估锚是**客户重合度**而非技术相关度。
- **元器件三特征筛选器**：低价值占比 × 高故障代价 × 高认证壁垒（宏发为信源本人展开的完整样本，三条全中：单只 6-7 元 / "不起眼的保护器件决定几十万上百万美元的安全" / 多年测试无法短期复制）
- **分部估值×兑现概率**：公司价值 = 原有业务(传统25-30x) + 新业务(未来利润×倍数×**订单兑现概率**)，绝不整体套 AI 估值

### B · 逆流复核：财报速读"从面到点"（260721 + 260804 实战强化）
> 财报**不是书，是字典**。**看前必答三问**：①我原来的判断是什么 ②哪些数字能证明 ③出现什么结果说明我错了。答不出就别看。

**第一层「面」· 六数字体检表**
| # | 数字 | 关键拆解/警戒 |
|---|------|--------------|
| 1 | 营业收入 | 收入=销量×单价；四拆：销量/单价/结构升级/**并购必须剔除看内生** |
| 2 | 毛利率 | **四象限**：收入↑毛利↑最理想；收入↑毛利↓警惕（价格战/成本涨/低毛利占比升/新厂爬坡） |
| 3 | **扣非净利润** | **不看归母**（补贴/处置/公允价值掺水）→ 改锚扣非。校验：扣非÷归母接近 1 = 利润来自主业（宏发 95.3% ✓ vs 京东方差 16.27 亿 ✗） |
| 4 | 经营现金流 | 判据 = 经营现金流净额÷净利润 **≥1**；<1 追三因（应收增/存货增/账期放长） |
| 5 | 应收 & 存货 | 应收增速>收入增速=用宽账期换增长；**⭐存货三分法（260804）**：原材料↑+在产品↑+**库存商品零增长** = 备产（好）；**产成品堆积+收入降 = 滞销（天大坏事）** |
| 6 | 资本开支 & FCF | FCF=经营现金流−资本开支；分维持性 vs 增长性；无订单硬扩产→未来变折旧减值 |

**⭐三段落差诊断法（260804 新增，六数字的串联读法）**——把 1/3/4/6 连成一条链：
```
收入增速 −  利润增速  = 盈利落差      （宏发：+32.05% − +19.89% = 12.16pct）
利润    →  经营现金流 = 转化率        （宏发：11.56 亿 → 1.14 亿 = 9.86%）
经营现金流 − 资本开支  = 自由现金流     （宏发：1.14 − 7.38 = −6.24 亿）
三段同向为负 = 规模是垫资买来的
```
- **反例边界**：扩产期出现该排序属正常，**判据在落差是否收敛**，不在落差是否存在。
- **配套铁律（260804 引自框架/两线交叉）**：`一边增长 一边备货 一边扩产 = 每个环节都是吞噬现金流的怪兽`——原文自比"**有点像高周转时期的房地产**"。

**第二层「点」· 财务版波士顿矩阵**（每条业务填 收入占比/增速/毛利率/定位）
- **现金牛**：养活公司并供血（宏发样本：传统继电器"给其他业务买时间和输血"）。警戒句=新业务能否在旧业务衰退前接上
- **明星**：高增长+份额扩张，**必须验证兑现链路**；两三年还停在送样/认证/扩产=**取消明星资格**
- **问题业务**：看 ROIC 有无改善 + 管理层是否反复推迟；**⭐披露粒度本身即信息（260804）**——判定依据不是表现差，而是**公司不单独披露其收入/毛利率/投入资本/经营现金流**
- **瘦狗**：理论上都是待砍，唯一豁免=核心产品必要销售配套。⚠️**实战中他的瘦狗格永远空着**，四象限有退化为分类修辞的风险

**第三层「管理层解释放最后」**：先用数字独立判断完，最后才看管理层的话——防叙事污染（呼应第0层）。

### C · 定价：估值三件套 ⭐v4.0 新增（此前模型最大缺口）

**① 五项加总式（260730 首次成文，通用骨架）**
```
企业价值 = 底座价值 + 成长价值 + 稀缺性溢价 + 期权价值(=0) − 风险折价
```
四条约束：
1. 只算**确定性较高**的增量（成长部分 ×0.8 折）
2. 未产生现金流的期权按 **0**
3. 风险必须反映（逐项列举相加）
4. ⭐**估值首先服务于"不出局"**——把估值功能从"求真值"改为"求生存"，与第0层"活得久"咬合。**这解释了他的估值系统性偏低是故意的，不是测不准。**

**⭐可替代性检验＝稀缺性溢价的唯一入口**（260730）："**规模领先 ≠ 行业缺了它就无法运转**"。京东方样本：客户仍可选华星光电/三星显示/LGD → 稀缺性溢价归零。
- ⚠️**该检验的不对称使用**：用在底座上，没用在期权上——而按其自身逻辑，期权价值恰恰全部取决于可替代性。

**② ROE—PB 逆推法（260730，重资产/周期股专用）**
```
合理 PB = (长期 ROE − g) ÷ (r − g)
r = 9%（十年期国债 2.5-2.8% + 股票风险补偿 6%），g = 2%
唯一变量 = 未来能长期维持多高 ROE
```
- **用法纪律**：敏感性表是**压力测试工具，不是目标价**（原文明确"1.24 元并不是我认为京东方只值 1.24 元"）
- 京东方三情景：保守 ROE 6%→2.1 元 / 基准 7-8%→2.6-3.1 元 / 乐观 9%+→3.6 元+；**乐观四前提有三条是资本纪律而非技术指标**（新产线利润覆盖折旧、FCF 明显增加、管理层不再无休止扩产）

**③ 三段估值法（260803，可执行简化版，用于生成买卖阈值）**
```
底座（成熟制造龙头 18-20× PE）→ "底价"
成长（能持续兑现 22-25× PE）  → 上沿
期权 = 0
现金流未复原前统一 × 0.9
```
- **⭐功能升级**：估值由"服务于不出局"进一步升级为**直接生成加减仓阈值**（宏发：跌破 30 继续买 / 超过 38 慢慢出手）
- ⚠️**内部矛盾**：九折施加在"测算价值"上却没施加在"我的卖点"上（成长上限 39×0.9=35.1，而定的卖出线仍是 38）
- **⭐M9 SOTP 正交性检查（260814）**：任何分部加总先标维度（产品/地区/客户/阶段），不同维度不得直接相加；必须附“分部利润合计→公司利润”的桥接。禾望把产品分部与海外地区增量混加，是首次明确反例。

**④ 通用商业公式的行业改写法（260728，估值前的建模步）**
`营业 = 流量 × 成交率 × 客单价` → 改写为行业变量。京东方样本：`显示收入 = 出货面积 × 每平方米价格 × 产品结构`；`利润 = 出货面积 × 单位面积利润 − 折旧 − 研发 − 期间费用 − 减值损失` → 收敛为六变量监测器（价格/面积/产品结构/稼动率/良率/折旧）。
- **⭐重资产第三增长曲线 = 停止扩产**（260728）：京东方 2025 经营现金流 488 亿 − 资本开支 400 亿 = FCF 88 亿；资本开支若降至 250 亿则 FCF→238 亿（+170%）。与算力资本化互为镜像 → 合并成**"资本开支方向盘"**：这家公司的下一个增长点是**多花钱还是少花钱**？

### D · 产业链拆解统一模板 ⭐v4.0 合并（原分散于阿斯麦/航天/配套工具三处）

> 四步走完，回答"这条链上哪个环节值得买"。前三步是描述，第四步才是判据。

**第 1 步 · 需求确定性八问链**（260727，最上游）
`需求从哪来 → 为什么必须在这里解决 → 用什么产品 → 需要哪些基础设施 → 产业链如何协作 → 钱如何流动 → 谁掌握瓶颈 → 谁能形成长期现金流`
- 是四步兑现范式的起点再往上游推一格：**需求确定性 → 技术确定性 → 需求刚性 → 订单兑现 → 财务确认**
- ⚠️ 第六问"钱如何流动"是他自己最常跳过的一问（航天系列连跳两篇）

**第 2 步 · 分层**（同一手法的三个样本）
| 样本 | 分层 |
|---|---|
| 光刻（260716） | 整机 → 光源光学 → **真空温控（既卖铲又卖水）** → 材料（按曝光次数计价）→ **量测检测（弹性最高）** |
| 商业航天（260730） | 运输层火箭 → 空间层卫星 → 星座与网络层 → 地面系统 → 应用层 |
| 组织逻辑（260723） | ①目标—任务—资源—结果（线性/结果前置=动员型）vs ②需求—收入—职业—参与—竞争—结果（循环飞轮=发展型）+ 十二特征判别器 |
- **通用免责条款**：**瓶颈 ≠ 利润归属**（"火箭只是搬运工"：重要性第一，投资属性往后靠）
- **因果倒转检查**：需求源常常不在你以为的那一层（发射频率的需求源在星座层，不在火箭层）

**第 3 步 · 现金流四阶段**（260801，补支付侧）
`战略资金（政府/军方/产业基金，买的是能力不是回报）→ 建设现金流 → 网络运营现金流 → 数据与应用利润`
自比"拿地—建设—卖—收物业费"。
- ⭐**核心纪律：建设现金流 ≠ 商业模式跑通**——"只能证明有人在修路，仅此而已""包工头的日子润不润，看下游销售顺不顺"

**第 4 步 · 两线交叉定环节**（260801，⭐唯一的判据步）
```
现金流迁移路径  ×  技术瓶颈迁移路径  →  交叉点 = 真正的价值环节
单看现金流 → 买到"修路的"；单看瓶颈 → 买到"重要但不赚钱的"
```
**甜点位五特点筛选器**：标准化 · 批量化 · 高价值量 · 重复采购 · 难以替代
- 详见独立框架文件：[两线交叉环节筛选法](../框架/2026-08-01_framework_两线交叉环节筛选法.md)
- **入场三信号前置化**（航天样本）：发射频率是否真升 / 卫星是否批量交付 / 终端成本与网络利用率是否改善

**配套（保留，不再展开）**：铲子公式 `刚需 × 替换难度 × 价值占比提升 × 资本开支效率 × 竞争格局`；真铲子三重叠加=谁赢都要用/越先进越贵/用了很难换；直接淘汰五类；半导体五层优先级；新材料三角 SiC×GaN×InP；玻璃基板三级标的（P0 Onto+LPKF > P1 SKC/Absolics+SamsungEM > P2 MKS+SUSS，⚠️窗口已顺延，见预测#84）。
**警句**：技术上重要 ≠ 好投资；好公司 ≠ 好价格。

## 四、持仓与回撤：处置四步链 ⭐v4.0 合并（原分散于原则9/四章/心法三处）

> M7 之前，回撤工具散在四个地方（可复盘尺、六层归因、五指标、情绪）。v4.0 按**使用顺序**串成一条链。

```
第0步 · 情绪退潮（260724）
  预期外事件三阶段：情绪(恐惧) → 行为(逃避) → 状态(破防)
  「亏损不是老虎」：本能对急性威胁有效，对慢性问题是加速器
  破防定义 = 不再处理事实、转为保护自己（删软件/怪市场/怪自己/加大下注，四行为同构）
  ⭐铁律：负面情绪出现时不做决定（⚠️ 与原则9"立即脱手"冲突，须自设退潮时长）
    ↓
第1步 · 可复盘尺（260708）
  这次亏损可不可复盘？
  可复盘 = 认知错误（修正系统）｜不可复盘 = 根本没形成认知（换赛道重来会重复踩坑）
    ↓
第2步 · 六层归因（260709）
  宏观折现率 → 产业回报率转向 → 行业 → 交易结构(杠杆/拥挤) → 未来价值vs价格 → 跟踪指标
  ⭐核心判据「价格调整 vs 价值下降」：
    PE缩但订单/客户/供不应求没变      = 价格调整（可扛/可加）
    CapEx下修+利用率降+ROI低于预期     = 价值下降（=四步兑现反向证伪，该走）
  落到一句话：跌的是 PE 还是 EPS？
    ↓
第3步 · 持有/离场五指标（260708）
  ①逻辑还在不在 ②价格是否已打满 ③业绩是否沿逻辑兑现
  ④行业趋势变没变 ⑤在等什么（须有具体事件对象 + 时间边界）
    ↓
⭐卡壳绕行阀 · 零基重买测试（260724）
  "如果我从没买过它，愿不愿在现在这个位置重新买入？"
  作用：把需要事后信息的判断题（逻辑崩没崩）换成当下可答的偏好题
  ⚠️ 失效条件：恐慌中会系统性输出"不买"→ 变成割在底部的合理化工具；且默认零摩擦成本
```

**⚠️ 整条链的共同短板**：六层归因、财报速读都是**后视镜**，擅长证伪已恶化的假设，对"逻辑刚拐点、财报还没反应"的左侧机会天然滞后。

- **终局**：国产控容量型（成为全球边际定价者），HBM/企业级/车规高端仍由三星/海力士/美光主导

### 机器人落地判据（260713）
- 真正的复杂度增量是**"接触"**；卡脖子在**可执行数据**（视频只记录"完成了什么"不记录"怎样完成"）
- **三段论**：购买动作(2026-28) → 购买工时(2028-32) → 完整劳动力(2032-35)

### 商业航天（260727/0730/0801 三篇合并结论）
- **需求侧**：五类业务底座（连接·观察·定位·传输·安全）+ 两类期权（计算·制造，信源自标期权）
- **供给侧**：五层结构；火箭 = **耗材**，可不投火箭而投其上游
- **支付侧**：To G 优先，第一笔钱买的是"独立发射能力、频谱与轨道资源、国家安全"而非财务回报
- **仓位结论**：⭐**零仓位，太早期**
- ⚠️ **"太早期了"几乎不可被证伪**（涨=建设期泡沫，跌=早说过太早期），三信号均无量化阈值
- ⚠️ **"既然有了可以抄的作业，那复制还不是我们的强项吗"** = 直接违反他自己在京东方用过的可替代性检验

### 模型基础设施化 + Jevons 悖论（260720）
- **蒸馏"探索—吸收"产业链**：美国探索 → 中国吸收；**前沿优势从"一年"缩到"几个月"**
- **⭐Jevons 悖论**：单次调用变便宜**不会**减少总算力需求（单次降半 × 调用增十倍 = 总需求增五倍）
- **利润转移**：模型层被挤薄 → 价值转移到**应用/Agent/工作流**
- **v4.0 接续（260805 谷歌）**：同一判断的第二次出现，对象换成**搜索**——"搜索从门户型业务变成基础设施"（微软 Windows 类比），AI 搜索 = **需求的 agent**；视频被 AI 理解后成为"可被调用的全球视频数据库"= **第二个搜索**。谷歌同时占住模型层与搜索层这两层基础设施

### 算力资本化 / 产业银行模式（260706）
- 英伟达从"卖铲子"升级为"给矿主融资+参股+分成"的产业投行；命名"算力税"
- **算力资本化三属性**：持续产现金流 / 可作融资抵押物 / 可作资本出让方式
- **瓶颈迁移三段**：GPU短缺 → 电力短缺 → **资产负债表/融资短缺**
- **双向未决**：平台升级 or 自融资泡沫

### 黄金 / 沃什 独立框架
- **黄金四对手盘**：美债 × 美元 × 通缩 × 股市；主权信用走薄逻辑链（百年级）；当前判断=2026年底-2027上半年调整结束，不会连续单边下跌
- **沃什三大制度变革**：去前瞻指引 / 拒财政货币化 / 2% 是全球承诺；**动态**：6-18 鹰派清零降息预期 → 7-02 转偏鸽，加息叙事双向摇摆

### 结构判断（持续有效的底层图景）
- **终端现金流监测体系**：消费是现金流源头，美国与中国同步滑坡
- **L 型分化**：99% 向下的社会结构演进
- **高成本世界效率军备竞赛**：能源危机 × 逆全球化 × AI 重工业化三重挤压

### ⭐M9 宏观价格四层 + 证据宽度门

**价格四层（260811/0817）**：`驱动力（利差/贸易/风险偏好）→传导通道（可兑换、杠杆、跨境搬运）→政策闸门（干预工具与市场解读成本）→最终价格（美元双边/一篮子/实际有效口径）`。日元与人民币两篇共同证明：驱动力强不等于价格必然同幅变化，通道与闸门决定压力被释放到汇率还是留在国内资产/信用体系。

**证据宽度门（260819）**：任何“全面/唯一/所有”宏观结论，至少同时检查：①名义/实际 ②同比/环比 ③总量/中位数或扩散度 ④正向/反向分项 ⑤领先/滞后指标。7 月宏观篇多数数字真实，却忽略同批数据中高技术制造与装备制造扩张，是“精确数字 + 不充分总体结论”的标准反例。

**制度—企业—分配接口（260818）**：宏观增长不能止于 GDP，要追到企业活跃率、就业、经营净收入与居民可支配收入。企业密度是水路中介，不是单因果发动机。

### 当前立场（2026-08-21 快照，会过期）
- **三情景**：基准=类滞胀分化｜坏=三重断裂｜好=全球化重启（概率最低）
- **⭐极端防御升级（260819）**：由“止盈缩仓”升级为动产、不动产“理论上应处尽出，注意，是所有的”，只靠克制与健康现金流过冬。⚠️未区分资产用途、负债、交易成本、执行周期与反转信号，属于作者观点，不是可直接执行策略。
- **AI 单线集中**：称 AI 供应链是唯一景气赛道、本人只参与该领域；同时承认订单依赖四大云厂商且客户开始融资。**这与自融资红线正面冲突**：全资产防御与单行业集中并存，不能再简单归类为“纯防守”。
- **AI 公司链新增观察**：禾望 800V 期权证据不足；生益科技公司级量/收入/毛利/现金流改善已确认，但 M9 技术代际、35% 缺口与 2—6 周交期未核实。方向判断必须过产品级证据门。
- **看空中国医疗/创新药**（260715 表态，260723 用组织逻辑线补上体制层因果，并扩容至新能源车/消费/新三样；⚠️新能源车恰是集中力量办成的，判据与结论对不上）
- **持仓侧**：宏发=第二仓位；京东方=持有；商业航天=零仓位。AI 集中只披露方向，未披露完整仓位比例；详见独立行为账本。
- **黄金**：短期利空、中期震荡（2026底）、长期（2027H1后）看涨
- **定投纪律**：方向优先于时机；**懒人法则：宽基 QDII 定投额 ≥ AI 主题定投额**

## 八、表达风格建模

- **句式**：长句+排比梳理历史因果链；短句+反问做批判（"凭什么？""谁赞成，谁反对？"）
- **绝对化表达**：强确定性时用；**对规则严格、对自己宽容**
- **类比库**：历史类比（跨百年）；体育类比（篮球赛/跳水vs足球）；生活化类比（财报=字典、阿斯麦=汽车品牌商、航天=拿地建设收物业费、宏发中报=高周转时期的房地产、谷歌=西方小米×西方百度、云=租土地电力厂房工具、订阅=学杂费）
- **数字精确癖**：说"亏了70%"不说"很多"（⚠️例外：偶发裸断言，如"军备竞赛规模不亚于AI和机器人"无数据支撑）
- **节奏**：开头直接抛核心问题不铺垫；中间数据→原理→推论分层递进；收尾给"需要追踪的关键数据"或悖论本身
- **教学式分步骤结构**（"从面到点""第一步…第二步…"）
- **⭐自认未完成的收尾（v4.0 新增特征，连续三次）**：京东方上篇"想了好几种估值模型都不理想……明天继续啃"、谷歌篇"写不动了，先到这儿吧，已经力竭了。明天继续"——**未完成态本身是第0层"生产者生产结论"的第一人称正面样本**（消费者不会公开半成品）。处理这类文章时须等下篇合并
- **允许文学收尾但必须配可执行重构问题**（罗曼罗兰式收尾出现于 260724）
- **⭐M9 绝对化升级**：出现“所有资产处尽”“唯一解法”“没有任何机会”等全称判断。此类句子更适合读作情绪权重和立场强度，不应直接当作有完整条件的策略。

## 九、模型可靠性评估

### 优势场景
- 长周期宏观分析（5年+）、利益明确的博弈局面、数据充分领域
- **防故事忽悠**：M9 证据门把送样、认证、订单、收入分层，比“一律期权=0”更能兼顾早期信号与叙事折价
- 产业链标的初筛：统一模板 10 分钟过滤伪机会；财报速读六数字快速排雷
- **⭐去叙事**：弹性检验（新增量÷现有收入<5%）是全模型最锋利的一把刀
- **⭐制度与价格传导**：利益结构、资本闸门和分配水路适合分析“驱动力为何没有等比例变成价格/收入”

### 失效场景
- 超级黑天鹅下历史对标失效
- **长期高估值市场系统性踏空**：层层保守叠加使估值系统性低于市价
- **竞争格局驱动的行业**（见盲区9）
- **后视镜属性**：对"逻辑刚拐点、财报还没反应"的左侧机会天然滞后
- **证据分布不均的宏观拐点**：容易从少数精确弱项推出总体结论；必须强制过证据宽度门
- **自己的持仓与偏好赛道**：纪律条款会系统性松动，其对重仓标的和 AI 链的分析应先按"持仓解释"读，再用正式披露校准

### 与其他流派的核心差异
| 流派 | 黄哥的差异 |
|------|-----------|
| 技术乐观派 | 只看经济激励与现金流能否持续 |
| 价值投资派 | 趋势判断优先于估值判断；精确时间节点而非"无限期持有" |
| 动量交易派 | 逻辑一致性优先于价格信号；反 FOMO 体系 |
| 浪淘沙（同库对照） | 黄哥管"该不该买、值多少钱"（月-年），浪淘沙管"今天加不加、何时撤"（日-周） |

## 十、使用指南

**评估一个企业**：钱从哪来 → 结构矛盾 → 关键拐点数据 → 失效条件 →（财报到手）三问 + 六数字 + 三段落差 + 波士顿矩阵
**评估一项政策/制度**：谁受益谁受损 → 权力支持函数 → 治症状还是病因 → 执行约束 → 历史对标 → 闸门是否存在 → 增长经哪条分配水路到居民
**评估宏观价格**：驱动力 → 传导通道 → 政策闸门 → 最终价格口径；全称结论再过名义/实际、同比/环比、总量/分布、正反分项、领先/滞后五项宽度门
**判断一个生意**：先排除 → 结构风险 → 关键数据 → 预设止损
**筛选产业链标的**：八问链 → 分层 → 现金流四阶段 → 两线交叉 + 甜点位五特点 → 四步兑现顺流预判 → 弹性检验 → 期权证据门 → SOTP 正交检查 → 估值定价 → 等价格 → 财报逆流复核
**遇到回撤**：走四章「处置四步链」（情绪退潮 → 可复盘尺 → 六层归因 → 五指标 → 零基重买）
**⭐引用他的结论前**：查 [独立信源行为账本](2026-08-21_model_黄哥信源行为账本.md)——持仓、口径、同赛道反例、证据门、退出条件五问

## 对抗步骤（反方视角）

1. **模型新增的是裁判规则，不是作者已经做到的能力。** 期权证据门、SOTP 正交和证据宽度门主要由本库从反面样本提炼；不能把“模型里已经修复”误写成“信源本人已经修复”。后续只有作者主动给出产品级证据、正交分部和反向数据，才算行为升级。

2. **“全资产防御 + AI 单线集中”可能不是精密策略，而是同一悲观叙事的两面。** 宏观越悲观，越需要把 AI 描述成唯一出口；AI 越像唯一出口，越容易降低其证据标准。若不设行业集中度和云厂商 CapEx 撤退线，所谓防守可能只是把风险从资产类别搬到单一因子。

3. **“向内生长”仍是最危险的优雅工具。** 它把有财报科目可查的问题换成没有独立科目的效率叙事；必须事前指定若判断错误会先在哪个数字上暴露，否则只是事后解释器。

4. **估值与仓位之间的缝尚未修复。** 京东方 3.10 元估值上限对应 5 元以下减仓点、宏发折后上限 35.1 对应 38 元卖点；阈值若不随坏消息重算，估值仍可能只是叙事对冲。独立行为账本负责继续追踪。

5. **极端防御仍未经纠错检验。** “所有资产处尽”没有可验证的执行记录与反转条件；若好情景兑现，无法区分作者及时切换、从未执行，还是事后改写。没有行动证据的仓位建议，不应进入模型核心原则。
