## 2. 作者的解释框架

作者把民主与专制的分界放在冲突处理方式，而不只是放在政府是否“办好事”：专制在讨论开始前关闭异议，失败的政策因此缺少公开纠错；民主则允许每个人表达与自身利益有关的感受，通过选举、公共讨论和程序把胜负从生死竞争降级为可逆竞争。其链条可以写成：

`利益冲突 → 公开表达 → 反方参与 → 计票/程序裁决 → 和平换人 → 失败经验保留为公共记忆`

全书关于反右、文革、六四、毛泽东评价、台湾和民主转型的文章，又补出“记忆—责任—制度”的接口：如果过去的暴力只能被遗忘，下一轮权力仍可把暴力包装成正确；如果记忆能进入公共讨论，权力就较难垄断正当性的定义。

## 3. 竞争性解释

替代解释是：公开计票只能处理偏好汇总，不能自动解决少数权利、信息不对称、国家能力和利益集团俘获；在社会信任不足时，选举甚至可能把冲突重新放大。区分方式是分别观察选举规则、司法独立、媒体自由、少数权利和败选者是否接受结果，不能把“有投票”直接等同于民主。

## 4. 反方视角与失效边界

本书是政论合集，题材和时点跨度较大，作者的自由主义立场贯穿全书；“专制=砍人头、民主=数人头”是有力的记忆钩子，但压缩了制度之间的连续谱。关于两岸、历史责任和民主转型的判断也受 1990—2000 年代语境影响。该模型适合做政治冲突的程序化检查表，不足以单独给出转型路径或判断任何现实政体的全部性质。
